# .gitignore

## ¿Para qué sirve?
Dice qué archivos no se suben a GitHub.

## ¿Qué hace?
- no sube las librerías de React (`node_modules/`)
- no sube React compilado (`public/assets/`)
- no sube las fotos subidas

## ¿Con qué se conecta?
- **Lo usa:** git.

## ¿Qué pasa si se borra?
| Si se borra… | Qué pasa |
|---|---|
| el archivo | se subirían a GitHub miles de archivos de librerías |
