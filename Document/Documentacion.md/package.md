# package.json

## ¿Para qué sirve?
Lista las librerías de React y los comandos de npm.

## ¿Qué hace?
- React, Tailwind (estilos), mapas, gráficas y PDF
- `npm run build`: compila React
- `npm run dev`: modo desarrollo
- `npm run lint`: revisa errores

## ¿Con qué se conecta?
- **Se usa con:** `npm install` (las descarga en `node_modules/`).

## ¿Qué pasa si se borra?
| Si se borra… | Qué pasa |
|---|---|
| el archivo | no se puede instalar ni compilar React |
