# tsconfig.json

## ¿Para qué sirve?
Configura TypeScript (el lenguaje de React en este proyecto).

## ¿Qué hace?
- dice cómo revisar el código de `src/`

## ¿Con qué se conecta?
- **Se usa con:** `npm run lint`.

## ¿Qué pasa si se borra?
| Si se borra… | Qué pasa |
|---|---|
| el archivo | `npm run lint` no funciona |
