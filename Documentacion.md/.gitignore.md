# .gitignore

## ¿Para qué sirve?
Le dice a **Git** qué archivos y carpetas **no** debe guardar ni subir a GitHub.

## Línea por línea
| Línea | Qué ignora | Por qué |
|---|---|---|
| `node_modules/` | Librerías de JavaScript | Se vuelven a descargar con `npm install`. Pesan mucho. |
| `build/`, `dist/`, `coverage/` | Carpetas que generan algunas herramientas | Se generan solas. |
| `.DS_Store` | Archivo oculto de Mac | No es del proyecto. |
| `*.log` | Archivos de registro | Cambian todo el tiempo. |
| `vendor/` | Librerías de PHP (Composer) | Se descargan con `composer install`. |
| `storage/logs/*` y `!storage/logs/.gitkeep` | Los logs, pero sí el archivo vacío `.gitkeep` | Así la carpeta existe aunque esté vacía. |
| `public/assets/` | El JavaScript y CSS compilados | Se generan con `npm run build` desde `src/`. |
| `public/index.html` | Copia que genera Vite | No se usa (ver `vite.config.ts`). |
| `public/uploads/` | Fotos subidas por el admin | Son datos, no código. |

## ¿Con qué se conecta?
Con las herramientas que **recrean** lo ignorado: `npm install` / `npm run build`
(ver `package.json`), `composer install` (ver `composer.json`) e `install.bat`.
