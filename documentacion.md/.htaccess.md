# .htaccess (en la raíz del proyecto)

## ¿Para qué sirve?
Es la configuración de **Apache** (el servidor web de Laragon). Cuando abres
`http://localhost/copiwaypro/...`, Apache lee este archivo y decide **a dónde mandar cada petición**.

## ¿Con qué se conecta?
| Dirección | Archivo | Para qué |
|---|---|---|
| → envía a | `public/assets/` | JavaScript y CSS compilados. |
| → envía a | `public/uploads/` | Fotos de productos. |
| → envía a | `public/favicon...`, `manifest.json`, `sw.js` | Íconos, app instalable y notificaciones. |
| → envía a | `public/index.php` | **Todo lo demás** (API y páginas). |

Con `start.bat` (sin Apache) este archivo no se usa: hace su trabajo `public/server-router.php`.

## Código explicado
```apache
<IfModule mod_rewrite.c>
    RewriteEngine On
```
Activa el módulo de Apache que permite "reescribir" direcciones.

```apache
RewriteRule ^assets/(.*)$ public/assets/$1 [L]
```
| Parte | Significado |
|---|---|
| `^assets/(.*)$` | Si la dirección empieza con `assets/`... `(.*)` captura el resto. |
| `public/assets/$1` | ...entrega el archivo de `public/assets/`. `$1` es lo capturado. |
| `[L]` | *Last*: si coincidió, no revisar las reglas siguientes. |

Ejemplo: `/copiwaypro/assets/main.js` → `public/assets/main.js`.

Las reglas van **en orden**:
1. `assets/...` → archivos compilados.
2. `uploads/...` → fotos subidas.
3. Íconos, `manifest.json` y `sw.js` → los entrega de `public/`.
4. `RewriteRule ^ public/index.php [L]` → **cualquier otra cosa** va a `index.php`.

Las rutas son **relativas** (sin `/` al inicio) para que funcione igual si el proyecto está en la
raíz o en una subcarpeta.
