# public/.htaccess

## ¿Para qué sirve?
Es la configuración de Apache para cuando el servidor apunta **directamente a la carpeta `public/`**
(por ejemplo, en un hosting). Hace dos cosas: enviar todo a `index.php` y proteger archivos privados.

## ¿Con qué se conecta?
| Dirección | Archivo |
|---|---|
| → envía a | `public/index.php` |
| Trabaja junto con | el `.htaccess` de la raíz (que manda las peticiones hacia `public/`) |

## Código explicado
```apache
RewriteCond %{REQUEST_FILENAME} !-f
RewriteCond %{REQUEST_FILENAME} !-d
RewriteRule ^ index.php [L]
```
| Línea | Significado |
|---|---|
| `RewriteCond ... !-f` | Si lo pedido **no** es un archivo que existe... |
| `RewriteCond ... !-d` | ...y **no** es una carpeta que existe... |
| `RewriteRule ^ index.php [L]` | ...entonces envíalo a `index.php`. |

Así las imágenes y el JavaScript se entregan directo, y todo lo demás lo responde PHP.

```apache
<FilesMatch "\.(env|sql|log)$">
    Require all denied
</FilesMatch>
```
Si por error queda un archivo `.env`, `.sql` o `.log` dentro de `public/`, nadie lo puede descargar
(tienen contraseñas o datos).
