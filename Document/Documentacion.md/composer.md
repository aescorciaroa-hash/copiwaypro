# composer.json

## ¿Para qué sirve?
Lista las librerías de PHP.

## ¿Qué hace?
- PHPMailer: para enviar correos
- web-push: para enviar notificaciones

## ¿Con qué se conecta?
- **Se usa con:** `composer install` (las descarga en `vendor/`).

## ¿Qué pasa si se borra?
| Si se borra… | Qué pasa |
|---|---|
| el archivo | no se pueden volver a instalar las librerías de PHP |
